## A. 当前总览

### A1. 项目是什么，现在能做什么

AgentGuild 面向本机项目管理员，希望把“派给 Agent 写代码 → 测试 → 独立审查 → 人工验收 → 合入项目”放进同一个控制台。当前是 Windows 桌面原型，不是已经正式发布的完整产品。

现有代码能够隔离工作区、保存候选和测试证据、手动启动只读审查、显示问题报告、进行独立的人工批准与本地 Git 合入，并对中断状态提供核对收尾入口。**P2-3 验证了离线模拟审查流程，没有验证真实模型审查质量或整条真实业务流程。** 更早的真实 Agent 接入试验不能代替这轮完整流程的验收。

交接对象是参与开发的同学及协作 Agent。当前任务是理解和核查交接规范；真实模型试跑另行安排。正式 UI/运行时统一、DSH reviewer、自动派单和自动合入不在本轮。
