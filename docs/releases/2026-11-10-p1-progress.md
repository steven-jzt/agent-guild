# Agent Guild 阶段进度版：2026-11-10

这是开发阶段的集成版本，不是正式桌面软件发布，也不表示第一阶段全部完成。

分支：`codex/reviewed-p1-3-20261110`。GitHub 原始基线：`6d2f12d`；包含 DSH 的 P1-1、TS 测试同步和 P1-3 提交，最后一份 DSH 交付为 `55ac138`，在此基础上由 Codex 修复验收发现的边界问题。本分支可供同学拉取修改；推送该分支不会改变 main。

## 当前架构

- `agent-guild/`：TypeScript 协议接入与实验，包含 Codex/DSH、JSONL/RPC 及 Windows 进程管理辅助程序。
- `p0-coordinator/`：Python + SQLite 协调内核，负责任务、文件预约、工作区、执行记录、候选版本、证据、人工批准和合入记录。
- 桌面原型：WebView2 壳复用现有 renderer，并通过 Python RPC 访问协调内核。正式产品界面及两套运行时的统一仍未完成。
- 核心流程：手动派任务 → Agent 修改工作区 → 冻结候选 → 必需测试/审查 → 人工验收 → 单独确认合入。真实 Agent 审查生产者尚缺，不能用普通测试冒充审查来放行。

## 本版本完成了什么

1. **P1-1 证据门禁**：按候选 SHA、必需检查类别和当前验证批次判定；新批次要求重新批准；作废最新失败不会恢复旧成功。旧批准表迁移可回滚、可恢复，同 ID 内容冲突保留两表并阻塞。
2. **TS 测试同步**：RPC 测试等待夹具明确就绪后才计算请求期限；覆盖延迟启动与启动等待超时，保留原协议错误断言。
3. **P1-3 Codex 协议**：区分成功、失败、中断及未知结果；保留早到完成事件，按 thread/turn 关联；超时不重发；支持中断请求；服务端审批默认拒绝，未知请求明确返回错误；默认保留 workspace-write/on-request 审批通道。
4. **Codex 验收补修**：中断请求应答不再冒充任务终态确认；只有观察到当前任务终态才返回 `confirmed=true`。RPC ID 排除布尔值、浮点数、集合、null 和越界整数；畸形响应不再被转换为空成功结果，错误原因向调用方传播。

本次补修只涉及必要适配器代码、离线回归和说明；没有修改合入逻辑、UI 或依赖，没有调用真实付费模型。新增 5 个测试方法，部分方法含多组边界子用例。
