```text

```

真实调用（无效 key）：

```powershell
$env:DEEPSEEK_API_KEY='invalid-test-key'
dsh --profile headless --json "Reply with exactly: OK"
```

返回：

```json
{"type":"status","phase":"turn_end","reason":{"kind":"error","error":{"message":"Authentication Fails, ...","code":"AUTH","status":401}}}
```

```text

start -> pid 39496
wait  -> exit_code 1
```

**结论**：`DshAdapter` 的 probe/start/wait/events 已对真实 `dsh` 验证；只差一个有效的 `DEEPSEEK_API_KEY`。  
下一步：设置有效 key，重跑同一命令，应得到 `final.text = "OK"`。
