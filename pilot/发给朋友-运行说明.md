## 4. 配 key（可选）

### DSH

```powershell
$env:DEEPSEEK_API_KEY="sk-..."
```

需要本机有 `dsh` CLI；没有就跳过 DSH，跑 dry-run。

### Codex + DeepSeek（不需要 OpenAI 账号）

```powershell

$env:CODEX_HOME="$PWD\.tmp\codex-deepseek-home"

$env:DEEPSEEK_API_KEY="sk-..."
```

## 5. 桌面壳（WebView2，推荐）

不需要 Electron，直接跑：

```powershell
cd 05-代码\p0-coordinator\webview2
.\bin\AgentGuildWebView2.exe
```

如果 PowerShell 执行策略拦截脚本，用 exe 直接启动即可；也可以：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1
```

验证：

```powershell
.\bin\AgentGuildWebView2Cli.exe --smoke
```

期望：

```text
WEBVIEW2_SMOKE {"smoke":true,"data":[...]}
```

现在 UI 里可以：

- 选项目、看任务；
- **启动 Run**（真正启动选中 agent：Codex-DeepSeek / 智谱 / App Server / DSH）；
- 看候选；
- **批准**；
- 填 repo/worktree 后 **合入**（真实 cherry-pick）。

真实启动 agent：

```powershell
cd 05-代码\p0-coordinator
python ..\..\08-试点\seed_agent_task.py
```

记下 `db` / `task_id` / `repo` / `worktree_for_merge`，设置 `GUILD_DB` 和 `DEEPSEEK_API_KEY`，启动 WebView2，选任务，agent 选 **Codex-DeepSeek** 或 **DSH**，check 填：

```text
python -m py_compile src/app.py
```

点 **启动 Run**，等候选变 `awaiting_human`，再 **批准 / 合入**。

想试审批/合入但不想启动 agent，先生成种子候选：

```powershell
cd 05-代码\p0-coordinator
python ..\..\08-试点\seed_webview2.py
```

把输出的 `db` 设成 `GUILD_DB`，再启动 WebView2。

需要 Microsoft Edge WebView2 Runtime；Windows 11 自带，Windows 10 通常随 Edge 安装。

### Electron（可选）

```powershell
cd 05-代码\p0-coordinator\electron
npm install
$env:ELECTRON_RUN_AS_NODE=$null
npm start
```

注意：

- 原机器 Electron 17/22/28/45/46-alpha 都崩 `0xC0000005`，是原机器环境问题；
- 换一台普通 Windows 可能能开；
- 如果也崩，不要怀疑业务代码，先用 WebView2 壳。`node smoke_cli.js` 可确认 Python 桥是好的。
