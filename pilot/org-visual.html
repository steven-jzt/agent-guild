一条任务的协调路径

任务→ 文件预约→ Worktree→ Agent 执行→ Scope 检查→ Candidate→ Evidence→ 人工批准→ 真实 cherry-pick→ Accepted
关键原则：agent 只在 worktree 内改预约文件；Coordinator 不替 agent 推理；合入必须经过人工批准与真实 Git 操作。
